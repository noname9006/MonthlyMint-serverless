# MonthlyMint Serverless

A serverless budget tracking application deployed on Vercel.

## Features

- Serverless architecture
- Fast and scalable
- Easy to deploy

## Deployment

This application is automatically deployed to Vercel. Any push to the main branch will trigger a new deployment.

## Local Development

To run locally:

```bash
npm install -g vercel
vercel dev
```

## API Endpoints

- `GET /api/hello` - Test endpoint that returns a success message

## Structure

- `index.html` - Main landing page
- `api/` - Serverless functions directory
- `vercel.json` - Vercel deployment configuration
